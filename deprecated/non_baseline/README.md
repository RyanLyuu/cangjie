# Non-Baseline Archive

This directory preserves code removed from the active tree during the baseline
cleanup. It contains the former RAG/progressive-KB translator, fragment-level
compiler adapters, mock/runtime-test infrastructure, analysis tooling, crawler,
generic rule library, obsolete shell entry points, their tests, and their
documentation/configuration.

The files retain their original relative layout for provenance. They are not
maintained as runnable commands and must not be imported by active code.
